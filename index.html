品牌简介

小火箭id 把线路与流量做成可按月使用的订阅，由用户在自己的设备客户端中导入。页面所说的官网、官方网站，指本页对套餐、客户端与操作顺序的说明，不代替各客户端开发者的软件商店页面。

服务按流量、同时在线设备和线路类型区分。基础线路适合一般浏览与资料同步；旗舰版增加流媒体与游戏向线路说明；团队版提高设备数量与流量上限，便于多人共用同一订阅管理。

阅读本页可以确认

  • 三种套餐的月付、年付与包含项目
  • 手机、电脑客户端的选择顺序
  • 从下单信息到导入订阅的步骤
  • 流量、设备数与连不上时先检查什么

使用场景

小火箭id 的网络加速面向需要稳定访问常用网站、办公资料和跨境学习内容的情况。出行时切换网络环境，也可以用同一订阅在手机和平板上分别连接，是否可用取决于所选套餐的设备数。

适合先想清楚的三件事

  • 主要在手机还是电脑上使用，决定先装哪一个客户端
  • 是否需要流媒体或游戏向线路，决定是否看旗舰版
  • 同一时间有几台设备在线，避免超出套餐设备数

不在本页承诺的内容

本页不提供测速排名、用户评分或第三方评测。线路质量会随运营商、时段和客户端设置变化，购买前以订单里的套餐说明为准。

客户端选择

客户端是真正发起连接的软件，小火箭id 提供的是订阅信息。请在设备自带的应用商店按客户端名称获取正版软件，本页不托管安装包，链接只指向本页说明。

手机优先

iPhone 与 iPad 用户若习惯小火箭一类客户端，先在 App Store 搜索并购买开发者发布的应用，再回到订阅页复制链接。安卓用户选择自己设备商店里仍在维护的代理客户端，确认它支持订阅导入。

电脑补充

Windows 与 macOS 适合需要长时间办公或大流量同步的人。先确定电脑客户端能读取订阅，再导入。不要同时在超过套餐允许的设备上保持在线。

选择时对照这四项

  • 系统版本是否仍受该客户端支持
  • 是否支持一键更新订阅，而不是逐条手填节点
  • 能否按规则或全局模式切换
  • 是否方便查看当前流量与连接状态

官网下载指什么

在本页选择客户端类型后，到对应应用商店完成获取。小火箭id 不提供改包、破解或来路不明的安装文件。若商店页面与本页名称不同，以商店中的开发者信息为准。

操作说明

1. 选定套餐

按月流量和同时在线设备数选择基础版、旗舰版或团队版。年付价格已列在套餐卡片中，用于一次付清全年的对照，不表示额外赠送未写出的流量。

2. 保存订阅信息

付款完成后保留订阅链接或订单中的导入说明。链接只应保存在自己的密码管理或订单记录里，不要发到公开群组。

3. 在客户端导入

打开已安装的客户端，使用“从 URL 添加订阅”或同等入口粘贴链接并更新。更新成功后会出现节点列表，再按延迟或用途选择一条连接。

4. 检查是否生效

连接后先打开一个日常网站，确认能打开再切换其他用途。若只是部分应用异常，先看客户端是规则模式还是全局模式，再考虑更换节点。

常见问题

小火箭id 和客户端是同一个东西吗？

不是。小火箭id 指订阅与套餐服务；客户端是安装在手机或电脑上的连接软件。需要两者配合：商店获取客户端，订单获取订阅。

官网下载是否直接提供安装包？

不提供。本页的下载说明只告诉你按系统去应用商店获取客户端，并在本页查看导入顺序，避免安装来源不清的文件。

基础版和旗舰版怎么选？

设备不超过 3 台、每月流量大约 100GB 且只需基础流媒体时，看基础版。需要 300GB、5 台设备、流媒体与游戏向线路说明时，看旗舰版。多人共用再看团队版的 1000GB 与 20 台设备。

订阅导入后没有节点怎么办？

先确认链接完整、客户端有网络权限，再手动更新订阅。若订单已过期或流量用尽，列表可能为空。仍为空时，用订单号联系对应套餐的支持渠道，不要反复尝试来源不明的配置。

可以超过设备数同时在线吗？

不建议，也不应依赖超限连接。基础版 3 台、旗舰版 5 台、团队版 20 台是同时在线上限。旧设备不用时先在客户端断开，再让新设备连接。

年付和月付的流量是否可以累计？

页面列出的是每月流量额度。年付只改变付款周期，对应金额为基础版 ¥150/年、旗舰版 ¥350/年、团队版 ¥850/年，没有另写可结转流量。
